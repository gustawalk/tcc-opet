OpetS v0.1.1

Novidades
- Crie checklists, peças e serviços sem sair da nova ordem de serviço.
- Consulte o histórico de ordens de serviço de um cliente pela tela de clientes ou pela lista de OS.
- Receba um aviso discreto quando houver uma atualização disponível.

Proteção de dados
- Banco de dados, anexos e novos backups passam a ser protegidos contra visualização casual de arquivos locais.
- A primeira abertura da nova versão cria um backup de recuperação e migra os dados existentes automaticamente.
- Backups podem receber uma senha opcional.

Importante
- Backups antigos da versão 0.1.0 continuam podendo ser importados.
- A senha de backup só é solicitada quando o arquivo foi protegido por senha.
- Não faça downgrade para a versão 0.1.0 depois da migração: ela não consegue abrir os dados protegidos.
