OpetS v0.3.0

Listagens e navegação
- Clientes, funcionários, estoque, modelos de checklist e ordens de serviço agora carregam os dados por páginas.
- A busca é realizada diretamente no banco de dados e evita carregar cadastros inteiros na memória.
- Navegue entre páginas, altere a quantidade de itens exibidos e retorne automaticamente ao início da lista.

Desempenho
- O aplicativo reutiliza a conexão protegida com o banco de dados, reduzindo o tempo fixo das operações.
- Consultas financeiras usam datas indexadas e calculam os custos das ordens sem consultas repetidas.
- Telas, relatórios e detalhes são carregados somente quando necessários, deixando o aplicativo inicial mais leve.

PDF e estabilidade
- A pré-visualização de documentos foi simplificada, mantendo o mesmo PDF para salvar e imprimir.
- Corrigido o descarte prematuro do PDF temporário durante a visualização.
- Corrigido o retorno indevido para a primeira página durante o primeiro carregamento.
