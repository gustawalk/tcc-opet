OpetS v0.3.1

Backup automático
- A configuração e os arquivos temporários do backup automático passaram a ficar na pasta de dados do aplicativo, com migração automática da localização antiga.
- Cada instalação registra localmente os arquivos que criou: a retenção nunca remove backups de outras máquinas nem backups manuais.
- Novos arquivos de backup nunca sobrescrevem um arquivo existente.
- O agendador aguarda a data do próximo backup e acorda somente quando necessário; com o recurso desativado, nenhuma verificação de hora em hora roda.
- Configuração corrompida é recuperada automaticamente a partir da versão anterior.
- Ativar o backup automático salva imediatamente; mudanças de pasta ou intervalo usam "Salvar configurações".
- O progresso do backup aparece em um diálogo fixo, e as datas do último backup são exibidas de forma relativa (hoje/ontem).
- Executar o backup com o recurso desativado agora é rejeitado, em vez de criar arquivos por engano.

Aparência
- Novo seletor de tema com as opções Claro, Escuro e Sistema, seguindo automaticamente o sistema operacional quando o tema do computador muda.
- Novo seletor de tamanho da fonte com as opções Pequena, Padrão e Grande, ajustando textos e interface.
- As preferências são salvas somente neste dispositivo.
