OpetS v0.4.0

Rede local
- Novo modo Host permite compartilhar o banco existente com até cinco computadores na mesma rede local, sem nuvem, internet, pasta SMB/NFS ou encaminhamento de porta no roteador.
- Novo modo Cliente usa todos os cadastros, estoque, ordens, configurações, dashboard, relatórios, PDFs e anexos diretamente no Host. Se o Host ficar indisponível, leituras e alterações são bloqueadas sem retornar silenciosamente ao banco local.
- A configuração mostra endereço, porta, estado, código de verificação e certificado fixado. Trocas de modo reiniciam o aplicativo para separar completamente os ciclos de armazenamento local e remoto.
- O Host pode acompanhar o último acesso dos computadores pareados, regenerar o código e revogar um dispositivo.

Segurança e backup
- O tráfego LAN usa HTTPS/TLS com impressão digital verificada, token exclusivo por dispositivo, compatibilidade exata de versão e idempotência nas alterações.
- O Cliente pode baixar backups manuais ou automáticos criados pelo Host. Importação, restauração, reset e configuração do backup oficial continuam exclusivas do Host.
- O sistema operacional pode solicitar uma regra de firewall para rede privada. A porta não deve ser publicada ou encaminhada no roteador de internet.

Limites
- O Host precisa permanecer ligado e com o OpetS aberto. Esta versão não oferece réplica offline nem eleição automática de outro Host.
- Sharding permanece adiado. Estoque, sequências, relatórios, configurações, anexos e backup continuam em um único banco autoritativo para preservar transações atômicas.
